# 파일 이름 일괄 변경 (BatchRename)

한 폴더에 있는 파일들을 골라서, 정한 순서대로 한꺼번에 번호를 붙여 이름을 바꾸는 Visual C++(Win32) 프로그램입니다.

예) 접두어 `여행_`, 시작 번호 `1`, 자릿수 `3` →
`여행_001.jpg`, `여행_002.jpg`, `여행_003.jpg` ...

## 빌드 방법
1. Visual Studio 2022에서 `BatchRename.sln`을 엽니다.
   ("C++를 사용한 데스크톱 개발" 워크로드가 설치되어 있어야 합니다.)
2. 구성을 `Release` / `x64`로 선택합니다.
3. **빌드 → 솔루션 빌드** (Ctrl+Shift+B)
4. `x64\Release\BatchRename.exe` 가 만들어집니다.

> Visual Studio 2019를 쓰는 경우 프로젝트 속성에서 플랫폼 도구 집합을 `v142`로 바꾸세요.

## 사용 방법
1. **[파일 선택...]** 을 눌러 폴더 안의 파일들을 고릅니다. (Ctrl / Shift 클릭, Ctrl+A로 전체 선택)
2. 목록 순서가 곧 번호 순서입니다. 순서를 바꾸려면
   - **▲ 위로 / ▼ 아래로**: 선택한 파일 이동 (여러 개 동시 선택 가능)
   - **이름순 정렬**: 탐색기처럼 숫자를 인식하는 이름순 (기본값)
   - **날짜순 정렬**: 수정한 날짜 순
   - **순서 뒤집기**
   - **목록에서 제거** (또는 Delete 키): 바꾸지 않을 파일 제외
3. **접두어 / 접미어 / 시작 번호 / 자릿수** 를 입력하면 "새 이름" 칸에 바로 미리보기가 나옵니다.
   - 새 이름 = 접두어 + 번호 + 접미어 + 확장자
   - **확장자 유지**를 끄면 확장자 없이 이름을 붙입니다.
4. **[이름 바꾸기]** → 확인을 누르면 한꺼번에 바뀝니다.

## 안전 장치
- 바꾸기 전에 새 이름끼리 겹치는지, 폴더에 같은 이름의 다른 파일이 있는지 검사합니다.
- 임시 이름을 거쳐 두 단계로 바꾸므로 `1.jpg ↔ 2.jpg`처럼 기존 이름과 새 이름이 겹쳐도 안전합니다.
- 중간에 실패하면(파일이 다른 프로그램에서 열려 있는 경우 등) 모든 변경을 원래대로 되돌립니다.
