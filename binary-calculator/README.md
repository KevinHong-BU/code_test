# 비트 워크벤치 (2진 데이터 계산·변환기)

브라우저에서 바로 쓰는 2진 데이터 도구입니다. 빌드나 설치가 필요 없습니다.

## 기능

- **진법 변환**: 2·8·10·16진수 동시 변환, 비트 칸을 눌러 개별 비트 토글,
  NOT / 2의 보수 / 시프트 / 바이트 순서 뒤집기, 1의 개수·패리티·표현 범위 표시
- **비트 계산기**: `+ − × ÷ mod −A`, `AND OR XOR NAND NOR NOT`, `<< >> >>> ROL ROR`,
  오버플로 표시, 피연산자별 입력 진법 선택
- **텍스트 ↔ 2진**: UTF-8 인코딩/디코딩(양방향), 문자별 코드 포인트와 바이트 표
- **IEEE 754**: float32/float64 비트 구조(부호·지수·가수), 정규수/비정규수/∞/NaN 판별

비트 폭(8/16/32/64)과 부호 해석(부호 있음 = 2의 보수 / 부호 없음)은 화면 위에서 고르며,
모든 정수 연산은 `BigInt`로 처리해 64비트에서도 정확합니다.

## 사용

`index.html`을 브라우저로 엽니다 (`bincalc.js`가 같은 폴더에 있어야 합니다).

## 구조

- `bincalc.js` — 파싱·변환·연산 핵심 로직 (DOM 없음, Node에서도 동작)
- `index.html` — 화면
- `test/bincalc.test.js` — 단위 테스트: `node --test test/bincalc.test.js`
