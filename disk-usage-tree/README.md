# Disk Usage Tree (로컬 웹 디스크 사용량 트리 뷰어)

Windows 11에서 드라이브 루트(예: `C:\`)부터 **모든 하위 디렉토리가 차지하는 용량**을
계산하여 브라우저에서 **트리 형태**로 보여주는 로컬 웹 프로그램입니다.

- Python 표준 라이브러리만 사용 (추가 설치 불필요)
- 서버는 `127.0.0.1`에서만 동작하여 외부에서 접근할 수 없음
- 폴더를 펼칠 때마다 하위 폴더를 크기순으로 정렬해서 보여줌
- 상위 폴더 대비 비율 막대, 파일 수, 폴더 수, 접근 거부 항목 수(⚠) 표시
- 폴더마다 "이 폴더의 파일" 합계 행 표시
- 행에 마우스를 올리면 [열기] 버튼으로 Windows 탐색기에서 해당 폴더 열기
- 정션/심볼릭 링크는 따라가지 않음 (중복 계산·무한 루프 방지)
- 스캔 진행 상황(폴더/파일 수, 현재 경로)을 실시간으로 표시하며, 스캔 도중 취소 가능

## 요구 사항

- Windows 11 (Linux/macOS에서도 동작)
- Python 3.8 이상 ([python.org](https://www.python.org/downloads/) 또는 Microsoft Store에서 설치)

## 실행 방법

1. `run.bat`을 더블클릭합니다.
   `C:\Windows`, `C:\System Volume Information` 같은 보호된 폴더까지 읽으려면
   **마우스 오른쪽 버튼 → 관리자 권한으로 실행**을 선택하세요.
2. 브라우저가 `http://127.0.0.1:8765/`로 자동으로 열립니다.
3. 드라이브를 선택하거나 경로를 직접 입력한 뒤 **[스캔 시작]**을 누릅니다.
4. 스캔이 끝나면 ▶를 클릭하거나 폴더 이름을 더블클릭해 하위 폴더를 펼칩니다.

명령줄로 실행할 수도 있습니다.

```bat
python server.py                 :: 기본 포트 8765
python server.py --port 9000     :: 포트 변경
python server.py --no-browser    :: 브라우저 자동 열기 끄기
```

종료하려면 콘솔 창에서 `Ctrl+C`를 누르거나 창을 닫습니다.

## 참고

- 표시되는 크기는 파일의 논리 크기 합계(탐색기의 "크기" 기준)입니다.
  압축된 파일이나 스파스(sparse) 파일은 실제 디스크 사용량과 다를 수 있습니다.
- 권한이 없어 읽지 못한 항목은 ⚠ 숫자로 표시되며, 크기 합계에서 빠집니다.
- 수백만 개 파일이 있는 `C:\` 전체 스캔은 디스크 속도에 따라 수십 초에서 몇 분이 걸릴 수 있습니다.
  결과는 메모리에 저장되며, 메모리에는 폴더 정보만 담깁니다.

## 구조

```
disk-usage-tree/
├── server.py          # 스캐너 + HTTP/JSON API 서버
├── static/index.html  # 트리 UI
└── run.bat            # Windows 실행 스크립트
```

| API | 설명 |
| --- | --- |
| `GET /api/roots` | 드라이브 목록과 사용량 |
| `POST /api/scan` `{"path": "C:\\"}` | 백그라운드 스캔 시작 |
| `GET /api/status` | 스캔 진행 상황 |
| `POST /api/cancel` | 스캔 취소 |
| `GET /api/children?path=...&limit=200` | 폴더의 하위 폴더 목록(크기순) |
| `POST /api/open` `{"path": "..."}` | 탐색기에서 폴더 열기 (Windows) |
