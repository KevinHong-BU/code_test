# Lode Runner — Apple II 웹 에디션

1983년 Apple II판 **Lode Runner**를 브라우저에서 즐길 수 있게 재현한 게임입니다.
빌드나 서버 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 원작에서 재현한 것

- 280×192 Apple II 고해상도 화면, 28×16 타일 맵, 주황 벽돌/흰 사다리 스타일과 하단 상태줄 (`SCORE… MEN… LEVEL…`)
- 타일 하나를 5단계로 나눠 움직이는 원작식 이동 (달리기, 사다리, 밧줄 매달리기, 낙하)
- 왼쪽/오른쪽 아래 벽돌 파기, 일정 시간 뒤 벽돌이 다시 메워짐
  - 메워질 때 구멍 속 경비병은 사라졌다가 맨 윗줄에서 다시 등장, 러너가 갇혀 있으면 목숨을 잃음
- 원작 알고리즘을 따른 경비병 AI (같은 층이면 직진, 아니면 층을 스캔해 러너와 가장 가까운 층으로 이동)
- 경비병이 금을 주웠다가 떨어뜨리고, 구멍에 빠지면 금을 구멍 위에 내려놓음
- 경비병 머리 밟고 지나가기, 함정 벽돌, 금을 다 모으면 나타나는 숨은 사다리
- 점수: 금 250 · 경비병 가두기 75 · 처치 75 · 레벨 클리어 1500, 레벨 클리어마다 목숨 +1
- 원작 키 배치 (`I` `J` `K` `L` 이동, `U` `O` 파기, `Ctrl+A` 포기) + 방향키/`Z` `X`
- 레벨 에디터 (원작의 Game Generator에 해당)

레벨 10개는 이 버전을 위해 새로 디자인했습니다 (원작 150개 레벨 데이터는 포함하지 않음).

## 조작

| 동작 | 키 |
| --- | --- |
| 이동 | 방향키 또는 `J` `L` `I` `K` |
| 왼쪽 / 오른쪽 파기 | `Z` / `X` 또는 `U` / `O` |
| 일시정지 (정지 중 `Q`로 종료) | `Esc` / `P` |
| 포기 (목숨 1개 잃고 다시 시작) | `Ctrl+A` |
| 속도 / 소리 | `+` `-` / `M` |
| 타이틀: 시작 / 레벨 선택 / 에디터 / 내 레벨 | `Enter` / `←` `→` / `E` / `C` |

터치 기기에서는 화면 아래에 방향 패드와 파기 버튼이 나타납니다.

## 레벨 에디터

타이틀에서 `E`. 도구를 고르고 클릭·드래그로 배치, 오른쪽 클릭으로 지웁니다.
`T`로 바로 테스트 플레이, 만든 레벨은 브라우저(localStorage)에 자동 저장되며
타이틀에서 `C`로 이어서 플레이할 수 있습니다. 내보내기/가져오기는 아래 텍스트 형식을 씁니다.

```
' ' 빈칸  '#' 벽돌  '@' 콘크리트  'H' 사다리  '-' 밧줄
'X' 함정  'S' 숨은 사다리  '$' 금  '0' 경비병(최대 5)  '&' 플레이어
```

## 파일 구성

```
lode-runner/
├── index.html
├── css/style.css
├── js/levels.js            # 레벨 데이터
├── js/game.js              # 게임 엔진, 렌더링, 사운드, 입력, 에디터
└── tools/check-levels.js   # 레벨 검사기: node tools/check-levels.js
```

`tools/check-levels.js`는 모든 레벨이 형식에 맞고, 금을 전부 모은 뒤 맨 윗줄까지
갈 수 있는지 확인합니다. 레벨을 고친 뒤 실행해 보세요.
