# 2진 정수 계산기 · IEEE 754 실수 변환기

컴퓨터 구조 / 디지털 논리 수업용 Windows 프로그램입니다. (C# WinForms, .NET Framework 4.8)

## 실행 방법 (Visual Studio Community)

1. `BinaryCalculator.zip` 압축을 풉니다.
2. **`BinaryCalculator.sln`** 을 더블클릭하여 Visual Studio Community(2019 / 2022)로 엽니다.
   - Visual Studio 설치 시 **".NET 데스크톱 개발"** 워크로드가 필요합니다.
   - .NET Framework 4.8 대상 팩이 없다고 나오면 안내에 따라 설치하거나,
     프로젝트 속성 → 대상 프레임워크를 설치된 4.7.2 등으로 바꾸면 됩니다.
3. **F5** (디버깅 시작) 또는 **Ctrl + F5** (디버깅하지 않고 시작)를 누릅니다.

외부 NuGet 패키지 없이 기본 라이브러리만 사용합니다.

## 기능

### ① 2진 정수 계산기 (2의 보수)
- 비트 수 선택: 4 / 8 / 16 / 32 / 64비트
- 피연산자 A, B를 **2진수 · 10진수 · 16진수** 중 아무 칸에 입력하면 나머지 칸이 자동으로 바뀜
  - 2진수/16진수: 비트 패턴 그대로 (`1111 1010`, `0xFA`), 앞에 `-` 를 붙이면 음수 (`-110`)
  - 10진수: 부호 있는 정수 (`-6`)
- 연산: `+  −  ×  ÷  %  −A(2의 보수)  NOT  AND  OR  XOR  <<  >>(산술)  >>>(논리)`
- 결과를 2진수/10진수/16진수로 표시, **N Z C V 플래그**, 오버플로 경고
- **계산 과정**: 음수의 2의 보수 만드는 법(비트 반전 + 1), 캐리를 포함한 덧셈 세로셈,
  뺄셈을 `A + (~B) + 1` 로 바꾸는 과정, 오버플로 판정(부호 비트 캐리 XOR) 등

### ② 실수 변환기 (IEEE 754)
- 단정밀도(32비트 float) / 배정밀도(64비트 double)
- **10진수 → 2진수**: `12.375`, `-0.1`, `3.4e38`, `1/3`, `inf`, `nan` 입력 가능
- **2진수 → 10진수**: `0 10000010 10001100000000000000000` 또는 `0x41460000`
- 부호/지수/가수 비트를 색으로 구분해 표시, 16진수, 종류(정규화/비정규화/0/무한대/NaN)
- 10진수 값 표시 규칙
  - |값| ≥ 10^7 이거나 |값| < 10^-4 → **지수 형태** (예: `1 × 10^30`, `1E+30`)
  - 그 사이의 값 → **일반 실수**와 **분수**로도 표시 (예: `12.375`, `99 / 8 = 12 와 3/8`)
- 실제로 저장된 **정확한 값**과 입력값과의 **오차**(예: 0.1 → 0.100000001490116119384765625)
- **변환 과정**: 소수부 ×2 반복, 정규화, 바이어스 더하기, 가수 비트 / 비트 → 값 계산식
- 내부 계산은 모두 BigInteger(무한 정밀도)로 하므로 반올림은 IEEE 754 규칙(가장 가까운 짝수)과 정확히 일치

### 글꼴 크기 조절 (수업 화면용)
- 위쪽 도구막대의 **가− / 가+ / 숫자 입력 / 기본 크기 / 수업용(24pt)** 버튼
- 단축키: **Ctrl + '+'**, **Ctrl + '−'**, **Ctrl + 0**(기본), **Ctrl + 마우스 휠**
- 8pt ~ 48pt, 모든 화면이 글꼴 크기에 맞게 자동으로 다시 배치됩니다.

```
BinaryCalculator.sln
BinaryCalculator/
├─ BinaryCalculator.csproj
├─ Program.cs                    프로그램 시작점

│  ├─ TwosComplement.cs          2의 보수 정수 변환·연산·계산 과정

│  ├─ FloatReport.cs             실수 변환 결과 / 변환 과정 문자열

└─ UI/                           화면
   ├─ MainForm.cs                메인 창, 글꼴 크기 조절
   ├─ IntegerCalculatorPanel.cs  ① 정수 계산기 탭
   ├─ FloatConverterPanel.cs     ② 실수 변환기 탭
   └─ UiKit.cs                   공통 배치 도우미
```
